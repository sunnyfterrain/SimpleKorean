# 답변 측정 결과

모델 `sonnet`(실행 시 `claude-sonnet-5-5`로 풀림), effort `low`, 질문 8개 × 2회.
숫자는 조건별 답변 전체의 합이고, 어절과 문장은 답변당 평균입니다.
`python3 evals/check_numbers.py`가 이 폴더의 답변 원문에서 표를 다시 계산합니다.

| 항목 | style 없음 | simple-english 2.1.1 | simple-korean 0.1.0 |
|---|---:|---:|---:|
| 답변 수 | 16 | 16 | 16 |
| 평균 어절 | 257.4 | 194.5 | 188.6 |
| 평균 문장 | 20.8 | 17.1 | 20.0 |
| em-dash | 1 | 0 | 0 |
| bold | 129 | 0 | 0 |
| header | 74 | 0 | 0 |
| bullet | 188 | 0 | 51 |
| table 줄 | 28 | 0 | 0 |
| 여닫는 말 | 0 | 0 | 0 |
| 번역투 | 11 | 4 | 4 |
| 꾸밈말 | 2 | 0 | 0 |
| 얼버무림 | 1 | 0 | 0 |

여닫는 말은 첫 문장의 여는 말과 본문의 닫는 말을 더한 수입니다.
번역투는 `ko_check.py`의 여섯 패턴 합계, 꾸밈말은 금지어 목록 적중 수, 얼버무림은 "것 같습니다" 류의 수입니다.
문장이 자연스러운지는 세지 못합니다.
