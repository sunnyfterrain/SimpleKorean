**"서버가 터졌다"는 한마디로, 서비스를 돌려주는 컴퓨터가 감당하지 못하고 멈췄다는 뜻입니다.**

**서버란?**
앱이나 웹사이트 뒤에서 일하는 컴퓨터입니다. 우리가 앱에서 버튼을 누르면 그 요청이 서버로 가고, 서버가 처리해서 결과를 돌려줍니다. 식당으로 치면 주방입니다.

**"터졌다"는?**
실제로 폭발한 건 아니고, 주방이 마비된 상태입니다. 주문이 한꺼번에 밀려들거나 고장이 나서 요리를 못 내보내는 상황이죠. 이때 사용자는 이런 화면을 만납니다.
- 화면이 계속 로딩만 됨
- "오류가 발생했습니다" 메시지
- 접속 자체가 안 됨

**주로 이런 이유로 터집니다**
1. **접속 폭주**: 이벤트나 선착순 오픈으로 사람이 한꺼번에 몰림 (식당에 손님이 100명 동시에 입장)
2. **프로그램 오류**: 새로 배포한 기능에 버그가 있어서 서버가 계속 실패함 (요리사가 레시피를 잘못 이해함)
3. **장비·연결 문제**: 서버 자체나 데이터베이스, 네트워크가 고장 남 (가스불이 꺼짐)

**기획자가 알아두면 좋은 점**
- 대형 이벤트나 프로모션 전에는 예상 접속자 수를 개발팀에 미리 공유해 주세요. 서버를 미리 늘려둘 수 있습니다.
- 장애가 나면 "무엇이 안 되는지, 언제부터인지, 어떤 화면에서인지"를 알려주면 원인 파악이 빨라집니다.
- "터졌다"는 보통 일부 기능이 아니라 서비스 전체나 큰 부분이 안 되는 심각한 상황을 가리킵니다.
