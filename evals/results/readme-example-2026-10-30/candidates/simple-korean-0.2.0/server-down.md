'서버가 터졌다'는 서비스를 돌리는 컴퓨터(서버)가 몰려드는 요청을 감당하지 못해 멈췄거나 매우 느려졌다는 뜻입니다.

식당에 비유하면 쉽습니다.
주방이 하루 100명분 음식을 만들 수 있는데 갑자기 1,000명이 주문하면, 주방이 마비되어 손님 대부분이 음식을 받지 못합니다.
앱이나 웹사이트에서는 화면이 계속 돌기만 하거나, 오류 화면이 뜨거나, 접속 자체가 안 되는 모습으로 나타납니다.

원인은 크게 세 가지입니다.
이벤트나 광고로 사용자가 갑자기 몰리는 경우가 있습니다.
새로 배포한 기능에 오류가 있어 서버가 스스로 멈추는 경우도 있습니다.
저장 공간이나 메모리가 가득 차는 경우도 있습니다.

기획자가 알아둘 점은 이벤트나 푸시 알림 발송처럼 사용자가 몰릴 일정을 개발팀에 미리 알려야 한다는 것입니다.
개발팀이 서버를 미리 늘려 둘 수 있기 때문입니다.
